โคตรเข้ม Halloween Lucky Draw — หน้าเว็บเหมือนภาพตัวอย่าง

1. แตก ZIP ด้วย My Files
2. เปิด github.com/new ใน Chrome สร้าง repository Public
3. อัปโหลดไฟล์ทั้งหมดจาก ZIP (ไม่ใช่ ZIP ทั้งก้อน) ไปยัง root ของ repository
4. Settings > Pages > Deploy from a branch > main > /(root) > Save
5. เปิด URL ที่ GitHub Pages แสดงใน Chrome > เมนู ⋮ > Add to Home screen > Install
6. กดสำหรับพนักงานเพื่อตั้ง PIN แล้วทดลองเกมก่อนใช้จริง

ของรางวัล 100: แก้ว 10, ลด 5 บาท 60, ลด 10 บาท 20, น้ำฟรี 10
ข้อมูลเก็บในเครื่องผ่าน localStorage ห้ามล้างข้อมูลเว็บไซต์หรือเปลี่ยน URL ระหว่างกิจกรรม
ไฟล์นี้เป็น PWA ไม่ใช่ APK และภาพที่ใช้เป็นพื้นหลังของหน้าเกมพร้อมปุ่มจริงและวงล้อจริงซ้อนทับ
